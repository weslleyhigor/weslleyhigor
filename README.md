## 👨‍💻 Sobre mim

Sou desenvolvedor com foco na criação de aplicações web e mobile utilizando **React**, **React Native**, **Expo** e **TypeScript**.

Atualmente, trabalho no desenvolvimento de soluções para o **Ministério Público do Estado do Acre**, participando da construção e evolução de sistemas institucionais, aplicações móveis e interfaces voltadas à experiência do usuário.

- 🚀 Desenvolvimento de aplicações web e mobile
- ⚛️ Especialidade em React, React Native e TypeScript
- 🎨 Interesse por UX/UI, acessibilidade e design de interfaces
- 🐳 Experiência com ambientes conteinerizados usando Docker
- 🔐 Atenção à segurança, qualidade e manutenção do código
- 🌱 Sempre aprendendo e aprimorando minhas habilidades
